# UI Reference Checklist

Use this before approving a Stitch screen or Codex implementation.

## Purpose

- [ ] Can a business user tell what the page is for in 5 seconds?
- [ ] Is the primary next action obvious?
- [ ] Is every visible metric real/useful?

## Layout

- [ ] No card-in-card clutter
- [ ] Tables used for operational collections
- [ ] Form sections use hierarchy/dividers, not decorative containers
- [ ] Product imagery is visible where relevant
- [ ] Information density is appropriate for desktop operations

## Anti-slop

- [ ] No giant gradient
- [ ] No neon/glass aesthetic
- [ ] No fake chart
- [ ] No fake “AI insight”
- [ ] No oversized marketing headline
- [ ] No excessive pills/badges
- [ ] No random blob/illustration
- [ ] No placeholder copy in final screen

## Interaction

- [ ] Loading state explains progress
- [ ] Empty state offers a next action
- [ ] Error state explains recovery
- [ ] Destructive action is explicit
- [ ] Status includes text, not color alone

## Responsive/accessibility

- [ ] keyboard focus visible
- [ ] labels are clear
- [ ] contrast readable
- [ ] mobile/tablet does not clip primary actions
