# Accessibility

Minimum quality bar:

- all inputs have visible/associated labels;
- keyboard focus is visible;
- interactive elements are actual buttons/links;
- dialogs manage focus correctly through the component library;
- status is not conveyed by color alone;
- text contrast is readable;
- icon-only controls have accessible names/tooltips where appropriate;
- images have useful alt text when they convey product identity;
- errors are connected to the affected field;
- mobile layout does not require precision tapping.

Accessibility is part of professional UX, not a decorative compliance checkbox.
