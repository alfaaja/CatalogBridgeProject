# AI-Assisted Development Disclosure

The assessment permits AI-assisted/vibe coding, but the candidate remains responsible for understanding the code and architecture.

## Tools

Potential workflow:

- ChatGPT: product/architecture brainstorming, specification, review, debugging guidance;
- Codex: repository implementation and refactoring;
- ECC: planning/testing/review/verification discipline;
- Stitch: UI design exploration/reference.

## Rules

- AI output is not accepted blindly;
- project documents define expected behavior;
- generated code must pass review/tests/build;
- the candidate must be able to explain major modules and trade-offs;
- no AI-generated fake data should be presented as real operational data;
- no secrets are pasted into AI prompts;
- Stitch-generated markup is not copied blindly; approved visual concepts are recreated using the project system.

## Interview phrasing

A concise honest explanation:

> “Saya menggunakan AI coding assistant untuk mempercepat implementasi dan review, tetapi scope, arsitektur, mapping data, acceptance criteria, dan validasi hasil saya definisikan dan verifikasi sendiri. Perubahan tetap diuji dengan lint/build/test dan saya bisa menjelaskan modul serta trade-off yang dipakai.”
